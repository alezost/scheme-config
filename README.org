** About

This repository contains Scheme code for various Scheme implementations.
Along with code written by me, it also contains code taken from other
places (mainly SRFIs).  In the latter case, there is a commentary about
code origin.

=scheme-config= is probably not the best name for this repository, but I
couldn't invent a better one, and since I already have such things as
[[https://github.com/alezost/emacs-config][emacs-config]], [[https://github.com/alezost/stumpwm-config][stumpwm-config]], [[https://github.com/alezost/shepherd-config][shepherd-config]], etc., I decided to use
this name.
